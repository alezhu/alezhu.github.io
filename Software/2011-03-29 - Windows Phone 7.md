# Windows Phone 7

WP7 уныл. Мысль пользоваться им давно отвергнута. Оставалась мысль только писать под него всякие app и продавать идиотамзаблудшим, купившим телефоны на этой ОС. Потому что Visual Studio и C# - это реально лучшее что есть среди других IDE и языков, соответственно, для разработки под мобильные платформы. Но условия разработки, вернее публикации приложений также гонят и эту мысль куда подальше. Но судя по "каментам" к http://www.gotdotnet.ru/blogs/bag/9724/25994/ - есть и довольные.
