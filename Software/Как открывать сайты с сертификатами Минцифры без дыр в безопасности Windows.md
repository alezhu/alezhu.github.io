
Если вам периодически приходится заходить на сайты вроде Госуслуг, налоговой или в веб-версию Сбера, вы наверняка сталкивались с требованием установить сертификаты Минцифры в систему или использовать Яндекс Браузер.

Ниже я подробно опишу, почему оба этих варианта небезопасны для основной операционной системы, почему попытка обойтись Firefox на практике ломается о странную логику сайта Сбербанка и как в итоге настроить удобный и изолированный запуск через WSL2.

### Почему не стоит ставить сертификаты Минцифры в основную систему

Корневой сертификат (Root CA) — это основа доверия в защищенных соединениях. Когда вы устанавливаете сертификат в системное хранилище Windows (`certmgr.msc`), операционная система начинает безоговорочно доверять любым сертификатам, которые им подписаны.

Главная проблема здесь в следующем:
1. **Риск перехвата трафика (Man-in-the-Middle).** Владелец закрытого ключа корневого сертификата может выпустить действительный сертификат для абсолютно любого домена в интернете — будь то Google, GitHub, иностранный банк или рабочая почта. Если такой трафик пойдет через оборудование с возможностью инспекции (например, СОРМ/ТСПУ), соединение будет расшифровано и зашифровано заново без каких-либо предупреждений браузера.
2. **Влияние на всю систему.** В системное хранилище Windows смотрят не только браузеры Edge или Chrome. К нему обращаются почтовые клиенты, мессенджеры, VPN-сервисы и средства разработки. Скомпрометированным оказывается всё окружение, а не только один отдельный сайт.
3. **Отсутствие независимого аудита.** Международные вендоры (Mozilla, Google, Apple) исключили российские сертификаты из общемировых списков доверия именно из-за несоответствия процедурам внешнего аудита.

Поэтому добавлять такие сертификаты в основную систему на рабочей машине — это заметная брешь в безопасности.

### Вариант 1: Изолированный профиль в Firefox

Первое разумное решение — использовать Firefox. В отличие от Chromium-браузеров, у Firefox собственное хранилище сертификатов, не зависящее от Windows.

Можно создать отдельный профиль только для посещения отечественных сайтов:
1. Закройте браузер, нажмите `Win + R`, выполните `firefox -P` и создайте профиль (например, `RuGov`).
2. Скачайте официальные сертификаты с портала Госуслуг.
3. Откройте новый профиль, перейдите в `Настройки -> Приватность и защита -> Сертификаты -> Просмотр сертификатов...` и на вкладке «Центры сертификации» импортируйте корневой и промежуточный сертификаты.
4. Запускайте этот профиль отдельной командой:
   ```cmd
   "C:\Program Files\Mozilla Firefox\firefox.exe" -P "RuGov" --no-remote
   ```

В теории это отличный вариант: основная система и повседневный браузер остаются чистыми.

### Проблема с кривой проверкой на стороне сервисов (пример со Сбером)

К сожалению, идеальный сценарий с Firefox часто разбивается о реализацию проверок со стороны веб-разработчиков. 

Яркий пример — сайт Сбербанка. Их страница проверки сертификатов подтверждает, что всё установлено корректно. Но при попытке открыть сам сайт вас всё равно перенаправляет на страницу с ошибкой: *«Возникла проблема... Возможно у Вас не установлены сертификаты»*.

Скрипты на сайте ожидают определенное поведение браузера, привязаны к Chromium-движку или ориентируются на конкретные User-Agent. В результате в Firefox сервис не работает, даже когда сертификаты на месте.

### Почему не хочется ставить Яндекс Браузер в Windows

Поскольку в Яндекс Браузере поддержка нужных сертификатов встроена по умолчанию, проще всего было бы использовать его. Однако установка этой программы в основную Windows создает свои серьезные проблемы с приватностью и безопасностью:

- **Вопросы доверия и приватности.** Яндекс работает в российской юрисдикции и плотно сотрудничает с товарищами майорами. Что именно, в каких объемах и кому этот браузер передает в фоновом режиме, где и сколько это хранится на серверах компании — хрен его знает. Давать закрытой проприетарной программе с таким бэкграундом полный доступ к своей рабочей системе и файлам — сомнительная идея.
- **Внедрение в систему.** Вместе с браузером устанавливаются фоновые службы обновления (`YandexBrowserService`) и задачи в Планировщике Windows, которые продолжают крутиться в памяти даже тогда, когда сам браузер закрыт.
- **Агрессивный маркетинг.** Приложение регулярно пытается перехватить ассоциации файлов (PDF, изображения, документы) и навязчиво предлагает стать браузером по умолчанию.

Держать такой комбайн прямо в основной системе ради периодического визита в банк или налоговую попросту нерационально.

### Виртуальная машина и конфликт с Hyper-V

Логичный шаг для изоляции — поднять виртуальную машину (VirtualBox или VMware) и запускать Яндекс Браузер внутри нее. 

Здесь есть очевидный минус: **время запуска**. Ждать 1–2 минуты, пока загрузится виртуальная машина, ради одного платежа или справки достаточно утомительно.

Кроме того, есть важный технический момент, о котором нужно знать заранее:
> Если вы решите использовать WSL2 (о котором речь пойдет дальше), Windows автоматически включит подсистему виртуализации **Hyper-V**.  
> С включенным Hyper-V программа **VirtualBox начинает работать крайне нестабильно и медленно** из-за конфликта за аппаратную виртуализацию процессора.  
> Поэтому если у вас уже есть рабочие виртуалки на VirtualBox, придется выбирать: либо оставаться в классической виртуальной машине без WSL, либо переходить с VirtualBox на **VMware Workstation** (VMware с Hyper-V сосуществует без проблем).

### Оптимальное решение: Яндекс Браузер внутри WSL2 + WSLg

Если вам не критичен VirtualBox или вы используете VMware, лучшим решением становится связка **WSL2** и **WSLg** в Windows 10/11. 

WSLg позволяет запускать графические Linux-приложения напрямую: окно браузера появляется прямо на рабочем столе Windows с аппаратным ускорением и общим буфером обмена. При этом:
- Запуск занимает всего 1–2 секунды;
- Браузер изолирован внутри контейнера Linux и не имеет доступа к реестру Windows, системным службам и системному хранилищу сертификатов.

#### 1. Скачивание deb-пакета
Перейдите на страницу [https://browser.yandex.ru/c/browser-linux](https://browser.yandex.ru/c/browser-linux) и скачайте установочный deb-пакет. Либо скачайте его сразу внутри консоли WSL Ubuntu:

```bash
cd ~
curl -L -o yandex.deb https://browser.yandex.ru/download?os=linux&package=deb
```

#### 2. Установка в Ubuntu
В терминале WSL выполните:
```bash
sudo apt update
sudo apt install ./yandex.deb -y
```
Пакетный менеджер автоматически подтянет все необходимые графические библиотеки.

#### 3. Запуск браузера
Проверьте работу программы:
```bash
yandex-browser
```
Через пару секунд на рабочем столе Windows откроется полноценное окно Яндекс Браузера, внутри которого уже работают все российские сертификаты.

### Создание ярлыка для запуска из Windows

Чтобы не открывать терминал каждый раз вручную, создайте обычный ярлык Windows:

1. На рабочем столе нажмите правой кнопкой мыши: **Создать $\to$ Ярлык**.
2. В поле расположения объекта укажите:
   ```cmd
   wsl.exe -d Ubuntu yandex-browser
   ```
   *(Если у вас используется другой дистрибутив, укажите его имя после ключа `-d`, например `-d Ubuntu-24.04`)*.
3. Задайте имя (например, `Яндекс Браузер (WSL)`).
4. В свойствах созданного ярлыка можно выбрать подходящую иконку, а в пункте «Окно» установить значение «Свернутое в значок», чтобы окно консоли не мелькало при запуске.

### Масштабирование интерфейса в WSL (125% или 150%)

На экранах ноутбуков или мониторах с высоким разрешением интерфейс Linux-приложений может оказаться мелким. Настроить масштаб можно двумя способами через консоль.

#### Способ 1. Параметр запуска Chromium (рекомендуемый)
Поскольку Яндекс Браузер построен на базе Chromium, он поддерживает встроенный ключ масштабирования.

- Для масштаба **125%**:
  ```bash
  yandex-browser --force-device-scale-factor=1.25
  ```
- Для масштаба **150%**:
  ```bash
  yandex-browser --force-device-scale-factor=1.5
  ```

Этот же ключ можно сразу дописать в ярлык Windows:
```cmd
wsl.exe -d Ubuntu yandex-browser --force-device-scale-factor=1.25
```

#### Способ 2. Системный масштаб интерфейса через gsettings
Если нужно изменить масштаб для графических программ внутри Ubuntu глобально, выполните в терминале WSL:

```bash
# Масштаб 125%:
gsettings set org.gnome.desktop.interface text-scaling-factor 1.25

# Масштаб 150%:
gsettings set org.gnome.desktop.interface text-scaling-factor 1.5
```

Альтернативный вариант для GTK-приложений — добавить параметры в файл `~/.bashrc`:
```bash
echo 'export GDK_SCALE=1' >> ~/.bashrc
echo 'export GDK_DPI_SCALE=1.25' >> ~/.bashrc
source ~/.bashrc
```
