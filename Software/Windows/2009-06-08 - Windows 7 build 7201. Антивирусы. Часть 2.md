# Windows 7 build 7201. Антивирусы. Часть 2

Как я писал в предыдущих постах, имели место 2 события - вышла бета DrWeb для Windows 7 и я поставил build 7201, чтобы убрать глюки с меню пуск-все программы. Как оказалось эти события не совместимы. Иными словами DrWeb на текущий момент работает только со сборкой 7100.
На 7201 наблюдается следующая ситуация. Во-первых, DrWeb тупо не ставится. Вернее ставится, но в конце процесса инсталляции вызывается сканер на проверку системы, что уводит систему в BSOD. Чтобы его поставить нужно при установке выбрать установку без ключа, тогда все поставится, но сканер не запустится. Собственно,  во-вторых, уже сказано выше - запуск сканера приводит со 100% вероятностью к BSODу. Также не запускатся драйвер для резидентной защиты Spider Guard. Работают только SpiderMail и SpiderGate. Короче толку с такого DrWeb - 0. Кроме того, весь интефейс веба (окна настроек, например) выглядит а`ля Windows9x/NT/2k - то есть типа классический вид. При этом этот интерфейс жутко тормозит. После отключения самозащиты интерфейс начинает выглядеть и работать нормально, но BSOD при запуске сканера и отказ работать SpiderGuard остаются.
На форуме DrWeb у людей есть такие же проблемы (хотя есть примеры, что все работает). Разработчики пока отмазываются фразами в духе - RC1 build 7100 была паблик - мы для нее выпустили бета-версию, для не паблик, коим является билд 7201, ничего делать не будем. Будут или нет - время покажет.
Пока сижу опять на Avast.
