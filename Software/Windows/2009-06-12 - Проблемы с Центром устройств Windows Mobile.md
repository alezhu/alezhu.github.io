# Проблемы с Центром устройств Windows Mobile

Дошли руки до синхронизации моего PocketPC с новой Windows 7 и тут вылезла новая ботва - не запускается Центр устройств Windows Mobile. Выдает окно типа "У Вас должна быть установлена следующая версия .Net Framework 4.20506... бла бла бла". Самое интересное, что именно эта версия и установлена - вместе с Visual Studio 2010 поставилась.
Ладно попробовал я переставить 4й framework - не ставится. Пообщался с "мировым разумом" - тот про такую проблему пока не знает. Запустил тогда Sysinternals Process Monitor и пошел смотреть почему этот центр не находит .Net 4, хотя тот стоит. Обнаружил, что на самом деле папку c 4.20506 он находит, но спотыкается на файле mscorwks.dll, которого там нет. Зато есть такой файл например в .Net Framework 2. Видать в Microsoft этот файл для 4 framework'a не нужен - или переименовали, или распихали по другим dll.
Судя по логам Process Monitor, также похоже, что при запуске Центр устройств (или ядро .Net ?) просматривает список установленых дотнетовских фрейморков и юзает последний. При этом видно также, что он пытается открыть файл wmdc.exe.config, которого нет. В этом конфиге в частности можно прописать какой framerwork использовать.
Родилась идея заставить Центр устройств принудительно использовать 2ой framework. Поскольку что там надо в .config писать я естественно не помнил наизусть, я нашел готовый кофиг от C#-кого компилятора по адресу c:\Windows\Microsoft.NET\Framework\v2.0.50727\csc.exe.config, скопировал его в c:\Windows\WindowsMobile\ и переименовал в wmdc.exe.config.
И вауля! Все заработало.
