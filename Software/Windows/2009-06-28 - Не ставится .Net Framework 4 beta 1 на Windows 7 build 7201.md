# Не ставится .Net Framework 4 beta 1 на Windows 7 build 7201 ?

Тогда мы снова идем к Вам =).
Итак появилась сабжевая проблема. Появилась после сноса Visual Studio 2010 и попытки повторной установки. Установка заканчивалась ошибкой "ERROR:The installer has encountered an unexpected error installing this package. This may indicate a problem with this package. The error code is 2908." Судя по логам, из-за того, что не ставился .Net Framework 4 Beta 1. Попытка отдельно установить последний также заканчивалась неудачей.
К сожалению сейчас я уже точно не вспомню те ошибки, что выдавал инсталлятор, но судя по истории поиска Google там присутствовали ошибки с кодами 0x80240017, 0x8002802F и 0x80070643. Копание в логах установки наводило на мысль, что не ставятся обновления Windows6.0-KB956250-v6001-x86.msu и Windows6.1-KB958488-v6001-x86.msu, которые пытается доустановить инсталлятор фреймворка. Их ручная установка также не удавалась.
В общем в ходе копания в инсталляторах этих обновлений и логических "умозаГлючений" появилась мысль что в билде 7201 они нафиг не нужны (\*). Поэтому родилась мысль заставить инсталлятор .Net Framework 4 пропускать их установку. После чего из пары файлов были выкинуты упоминания об этих обновлениях и установка прошла как по маслу.
Итак, рассказываю порядок действий, если у Вас сабж.
1. Запускаете установку .Net Framework 4 Beta 1 и доходите до того момента, когда инсталлятор выдаст окошко с ошибкой и ссылокой на лог установки. Окошко не закрываете.
2. В это время все файлы необходимые для установки распакованы во временную папку. Вам нужно ее найти. Обычно она лежит в корне какого-либо вашего жесткого диска и имеет длинное имя из случайных цифр и букв. В моем случае это было "f7e95ae8a299f22c6b848dda104eefc0". Внутри нее в частности должны быть MSU-файлы, указанные выше + их 64 битные копии. Скопируйте эту папку в другое место - в дальнейшем мы будем работать с копией.
3. Вернитесь в окно с ошибкой установки и нажмите OK - инсталлятор удалит временную папку.
4. Перейдите в копию папки , которую вы только что сделали и откройте файл ParameterInfo.xml на редактирование.
5. Вам нужно найти Exe-разделы для файлов обновлений и удалить их. раздел начинается примерно так: **<Exe Name="Windows6.0-KB956250-v6001-x86.msu"**и заканчивается ближайшим **</Exe>**. Нужно удалить все разделы для обоих обновлений. Скорее всего Вам нужно будет удалить строки с 636ой по 870ую. Сохраните файл и закройте.
6. Теперь уже в подпапке Client откройте файл ParameterInfo.xml и выполните теже операции (тут удаляются строки с 580ой по 814ую).
7. Вернитесь обратно в папку-копию выполните команду **Setup.exe /x86 /x64**
После описанных действий все должно поставится без проблем.
ЗЫ. Если не хотите руками править XML - вот [тут](http://www.box.net/shared/ha9acyvdbf) я положил уже правленые. Нужно просто распаковать их с заменой
UPD: (\*) как оказалось не все так однозначно. Сегодня я поставил на виртуалку еще одну W7 и .NET 4 встал в ней без всех этих плясок с бубнами. Также в основной системе не ставится XNA Game Studio 3.1, а в виртуалке - опять же без проблем. Из чего можно сделать вывод, что проблема не в Windows 7, а в моих шаловливых ручках, которые что-то где-то накрутили не того =/.
