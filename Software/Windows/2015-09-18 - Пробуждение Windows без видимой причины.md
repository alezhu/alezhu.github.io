# Пробуждение Windows без видимой причины

В просмотре событий наблюдалось
*Системное время синхронизировано с аппаратными часами.
Таймер - Будет выполнено назначенное задание "Maintenance Activator", запросившее вывод компьютера из спящего режима.*
Синхронизацию времени я вырубил. Это не помогло.
Выключал пробуждения от мышек и вообще USB. Не попомогало
На сетевом адаптере галку не снимал, но там стот пробуждение только по магическому пакету.
Пересмотрел в планировщике заданий все задачи, где стоит галка "выводить из спящего". Даже скрипт на PowerShell написал для поиска таких задач.
ни-фи-га.
Что самое интересное задания Maintenance Activator в планировщике нет.
Оказалось хитрожопые микрософтовцы, по своей старой привычке, прячут это задание от пользователя. Подробности нашел [тут](http://www.outsidethebox.ms/14062/)
Отключается оно правда просто, главное знать где. А именно Панель управления -> Безопасность и обслуживание -> Обслуживание -> Автоматическое обслуживание -> Изменить параметры обслуживания -> снимаем галку "Разрешить задаче обслуживания пробуждать мой компьютер..."
Картинки (на английском правда) есть вот [тут](http://www.tenforums.com/tutorials/3090-automatic-maintenance-change-settings-windows-10-a.html) или [тут](http://theohbrothers.com/prevent-windows-10-from-waking-up-from-sleep-for-system-maintenance/)
Ну а если вам это не помогло, смотрите все причины [тут](http://superuser.com/questions/494235/how-can-i-prevent-my-computer-from-waking-up-accidentally)
