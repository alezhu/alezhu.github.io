IE 8. Панель меню над строкой адреса

IE 8. Панель меню над строкой адреса. “В восьмой версии программы строка меню, если ее включить в настройках панели инструментов, располагается между полем для ввода адресов и линейкой табов. Кому-то подобная схема расположения элементов может показаться неудобной и захочется передвинуть строку меню на привычную позицию, то есть поместить ее аккурат под заголовком окна браузера. Стандартными средствами переместить строку меню не удастся, а вот нестандартными - вполне. Для этого нужно вновь открыть редактор системного реестра, добавить в ветку HKEY_LOCAL_MACHINE\Software\Microsoft\Internet Explorer\Toolbar\WebBrowser новый DWORD-параметр ITBar7Position, задать ему единичное значение и перезапустить программу” ©перто отсюда. Там еще кое что есть про настройку IE8 ...

Не ставится .Net Framework 4 beta 1 на Windows 7 build 7201

Не ставится .Net Framework 4 beta 1 на Windows 7 build 7201 ? Тогда мы снова идем к Вам =). Итак появилась сабжевая проблема. Появилась после сноса Visual Studio 2010 и попытки повторной установки. Установка заканчивалась ошибкой “ERROR:The installer has encountered an unexpected error installing this package. This may indicate a problem with this package. The error code is 2908.” Судя по логам, из-за того, что не ставился .Net Framework 4 Beta 1. Попытка отдельно установить последний также заканчивалась неудачей. К сожалению сейчас я уже точно не вспомню те ошибки, что выдавал инсталлятор, но судя по истории поиска Google там присутствовали ошибки с кодами 0x80240017, 0x8002802F и 0x80070643. Копание в логах установки наводило на мысль, что не ставятся обновления Windows6.0-KB956250-v6001-x86.msu и Windows6.1-KB958488-v6001-x86.msu, которые пытается доустановить инсталлятор фреймворка. Их ручная установка также не удавалась. В общем в ходе копания в инсталляторах этих обновлений и логических “умозаГлючений” появилась мысль что в билде 7201 они нафиг не нужны (*). Поэтому родилась мысль заставить инсталлятор .Net Framework 4 пропускать их установку. После чего из пары файлов были выкинуты упоминания об этих обновлениях и установка прошла как по маслу. Итак, рассказываю порядок действий, если у Вас сабж. ...

Не запускается Журнал событий Тогда мы идем к вам

Не запускается Журнал событий? Тогда мы идем к вам Вернее это вы идете сюда, читать как исправить. Короче проблема - Заметил, что не хочет запускаться служба “Журнал событий”. Попытка запустить ее вручную приводит к диалоговому окну с ошибкой: “Не удалось запустить службу Журнал событий Windows на Локальный компьютер. Ошибка 5: Отказано в доступе.” Гугление давало много вариантов, но ни один не прокатил. Прокатил следующий - на папку %winDir%\System32\winevt\ и ее файлы и папки дается полный доступ для пользователя Local Service (под которым и работает Журнал событий). Возможно еще нужно тоже самое сделать для папки %winDir%\System32\LogFiles\ ...
