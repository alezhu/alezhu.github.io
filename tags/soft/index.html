Не ставится .Net Framework 4 beta 1 на Windows 7 build 7201 ?

Не ставится .Net Framework 4 beta 1 на Windows 7 build 7201 ? Тогда мы снова идем к Вам =). Итак появилась сабжевая проблема. Появилась после сноса Visual Studio 2010 и попытки повторной установки. Установка заканчивалась ошибкой “ERROR:The installer has encountered an unexpected error installing this package. This may indicate a problem with this package. The error code is 2908.” Судя по логам, из-за того, что не ставился .Net Framework 4 Beta 1. Попытка отдельно установить последний также заканчивалась неудачей. К сожалению сейчас я уже точно не вспомню те ошибки, что выдавал инсталлятор, но судя по истории поиска Google там присутствовали ошибки с кодами 0x80240017, 0x8002802F и 0x80070643. Копание в логах установки наводило на мысль, что не ставятся обновления Windows6.0-KB956250-v6001-x86.msu и Windows6.1-KB958488-v6001-x86.msu, которые пытается доустановить инсталлятор фреймворка. Их ручная установка также не удавалась. В общем в ходе копания в инсталляторах этих обновлений и логических “умозаГлючений” появилась мысль что в билде 7201 они нафиг не нужны (*). Поэтому родилась мысль заставить инсталлятор .Net Framework 4 пропускать их установку. После чего из пары файлов были выкинуты упоминания об этих обновлениях и установка прошла как по маслу. Итак, рассказываю порядок действий, если у Вас сабж. ...
