IE 8. Панель меню над строкой адреса

IE 8. Панель меню над строкой адреса. “В восьмой версии программы строка меню, если ее включить в настройках панели инструментов, располагается между полем для ввода адресов и линейкой табов. Кому-то подобная схема расположения элементов может показаться неудобной и захочется передвинуть строку меню на привычную позицию, то есть поместить ее аккурат под заголовком окна браузера. Стандартными средствами переместить строку меню не удастся, а вот нестандартными - вполне. Для этого нужно вновь открыть редактор системного реестра, добавить в ветку HKEY_LOCAL_MACHINE\Software\Microsoft\Internet Explorer\Toolbar\WebBrowser новый DWORD-параметр ITBar7Position, задать ему единичное значение и перезапустить программу” ©перто отсюда.
