# Синхронизация файлов

Почему то ActiveSync не дает указать папку на большом компе для синхронизации файлов с покетом.
Но его можно поменять в реестре по адресу

HKEY\_CURRENT\_USER\Software\Microsoft\Windows CE Services\Partners\35a40c49\Services\Synchronization\Briefcase Path

(Я думаю, строка 35a40c49 может быть на другом компе или с другим наладонником совсем другой)
Правда папка все равно задается относительно Моих документов. И после изменения надо перезапускать ActiveSync
