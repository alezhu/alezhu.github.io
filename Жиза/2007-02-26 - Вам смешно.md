# Вам смешно?

Итак есть "классный" тест - [Тест Виконт](http://lleo.aha.ru/test/vicont/index.htm). Сходите по ссылке, пройдете этот тест и скорее всего получите вот эту картинку
![](http://static.flickr.com/175/402481427_495568b20a_o.jpg "Текст Виконт")  
Ниже картинки Вам также предложат код, который можно вставить в очередную запись в своем блоге. Не спешите. Для начала попробуйте этот код вставить в свой блог из браузера, отличного от того, под которым вы проходили тест (Если юзаете IE или надстройки, то Semagic отпадает). Результат Вас неприятно удивит. И именно этот результат между прочим будет виден всем остальным. Особо нетерпеливые могут смотреть  сюда:
